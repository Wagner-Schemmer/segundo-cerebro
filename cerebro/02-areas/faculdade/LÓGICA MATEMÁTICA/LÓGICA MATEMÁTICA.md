## 📚 Conteúdo Programático

### Módulo 1: Lógica Proposicional
- [ ] Proposições, conectivos, tabelas-verdade
- [ ] Tautologias, contradições, contingências
- [ ] Equivalências lógicas, leis de De Morgan
- [ ] Argumentos válidos, regras de inferência

### Módulo 2: Lógica de Predicados
- [ ] Quantificadores: universal, existencial
- [ ] Variáveis livres e ligadas
- [ ] Regras de inferência com quantificadores
- [ ] Teoremas de validade

### Módulo 3: Teoria dos Conjuntos
- [ ] Operações: união, interseção, diferença, complemento
- [ ] Produto cartesiano, relação de potência
- [ ] Relações: equivalência, ordem
- [ ] Funções: injetora, sobrejetora, bijetora

### Módulo 4: Demonstrações Matemáticas
- [ ] Demonstração direta, por contraposição
- [ ] Demonstração por contradição (reductio ad absurdum)
- [ ] Indução matemática (finita, forte)
- [ ] Demonstração por casos, contraexemplo
